# 🛍️ StoreLocator

A full-stack web application to find nearby stores for products.

## 🚀 Features
- User Login & Register
- Product listing with images & ratings
- Find nearby stores using GPS
- Interactive map with Leaflet.js
- Ratings & Reviews
- Add to Cart

## 🛠️ Tech Stack
- Spring Boot, MySQL, HTML, CSS, JavaScript, Leaflet.js

## ⚙️ Setup
1. Create MySQL DB: `storelocator_db`
2. Update `application.properties`
3. Run: `mvn spring-boot:run`
4. Open: `http://localhost:8080`
